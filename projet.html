Mes projets

Voici quelques-uns de mes projets réalisés dans le cadre du BTS SIO option SLAM ou en autonomie. Ils illustrent mes compétences en développement web et en logique de programmation.

Projet : Site web de gestion automobile

Ce projet consistait à développer une application web permettant de gérer un parc automobile : ajout, modification et suppression de véhicules.

  • Langages utilisés : HTML, CSS, PHP, SQL
  • Base de données : MySQL (via phpMyAdmin)
  • Outils : Visual Studio Code, XAMPP, GitHub
  • Réalisation : Création solo
  • Durée : 1 semaine

Ce projet m’a permis de mettre en pratique la modélisation Merise, la structuration d’une base de données relationnelle, ainsi que la gestion de formulaires et de sessions utilisateurs.

Projet : Clone de Temple Run (Jeu Web)

Développement d'un mini-jeu de type "endless runner" inspiré du célèbre jeu Temple Run, directement jouable dans le navigateur. L'objectif est d'esquiver les obstacles le plus longtemps possible.

  • Langages utilisés : HTML, CSS, JavaScript (WebGL / 3D)
  • Outils : Visual Studio Code, Vercel, GitHub
  • Réalisation : Création solo

Ce projet m’a permis de travailler sur la logique de jeu (game loop), la génération dynamique d'obstacles, la gestion des collisions et le rendu 3D dans le navigateur.

Projet : M.I.A - Assistant IA Cloud

Développement d'une interface conversationnelle intelligente (chatbot) connectée à l'API Google Gemini. L'application intègre des profils personnalisés, la génération d'images, et l'analyse de fichiers.

  • Langages utilisés : HTML, CSS, JavaScript
  • APIs & Bibliothèques : Gemini API, Pollinations.ai, Mermaid.js, Highlight.js
  • Réalisation : En collaboration (Yacine & Syrine)

Ce projet complexe m'a permis de manipuler des API externes (LLM), de gérer des états asynchrones complexes en JS, et de concevoir une UI/UX moderne avec un effet "Glassmorphism".

Projet : Jeu d'Aventure Textuel (Python)

Développement d'un jeu de rôle textuel (RPG) jouable dans le terminal, inspiré de l'univers d'un célèbre manga (Lycée A.U.). Le joueur explore différents lieux, gère des ressources et affronte des ennemis.

  • Langages utilisés : Python
  • Concepts : Algorithmique, conditions, boucles, fonctions
  • Structures de données : Listes, Dictionnaires
  • Réalisation : Création solo

Ce projet m'a permis de consolider ma logique de programmation en créant un système de combat au tour par tour, une gestion d'inventaire complexe (objets clés vs consommables), et un système de déplacement dynamique.
